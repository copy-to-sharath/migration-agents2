# Codegen Config

Local config for the code generation stage.

## Parameters
- `generated_root`: folder for generated solutions (default `generated/`).
- `api_name`: optional single API name to generate.
- `api_namespace`: root namespace for API projects.
- `test_namespace`: root namespace for test projects.
- `max_apis`: optional cap for APIs generated in a run.
- `run_id`, `artifact_version`, `output_root`: use global defaults if not set.
